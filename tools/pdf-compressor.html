How it works

This tool rebuilds your PDF with optimized object streams, deduplicates repeated resources and strips redundant metadata — the same lossless techniques used by professional optimizers. Because it never re-encodes images or text, quality is identical to the original.

Typical savings

  • Office-exported PDFs (Word/PowerPoint): 10–40% smaller.
  • Already-optimized PDFs: a few percent.
  • Scanned image-only PDFs: small gains — image content is already compressed.

FAQs

Is compression really lossless?

Yes. Every page, image and font is copied exactly — only the file structure is optimized.

Is my document uploaded?

No. The whole process runs in your browser via JavaScript.
