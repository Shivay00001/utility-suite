How to compress an image

  1. Drop one or more images into the box above.
  2. Choose quality (80 is the sweet spot) and optional max size.
  3. Click Compress images and download each result.

Why compress images?

Large images slow down websites, eat mobile data and bounce off email attachment limits. Compressing to quality 80 typically cuts 50–70% of file size with no visible difference — the same technique used by tools like TinyPNG.

FAQs

What's the best quality setting?

80 for photos on the web. Use 90+ for print, 60–70 when every kilobyte counts.

Does it work for PNG with transparency?

Yes — choose PNG output to keep transparency, or WebP which also supports it at smaller sizes.

Is there a file size limit?

Free: 25 MB per image, 5 at a time. Pro raises both limits and removes ads.
