Why generate passwords locally?

Many "free" password tools run on a server — you have to trust they don't log what they generate. This one uses your browser's cryptographically secure random number generator (crypto.getRandomValues) and the page works fully offline. There is physically no server to leak to.

FAQs

Do you store my passwords?

No. Generation happens in your browser memory only. Refresh the page and it's gone.
