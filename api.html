Quickstart

curl -X POST https://api.tools.visionquantech.com/v1/images/compress \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@photo.jpg" -F "quality=80" -F "format=webp" \
  -o photo-compressed.webp

Authentication & limits

All requests use Authorization: Bearer <key>. Rate limits are per key; 429 responses include a Retry-After header. Webhooks notify you on large batch jobs.
